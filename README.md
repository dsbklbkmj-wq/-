# 퇴사하고 싶어요 — 부장님 방어전 (v3)

> 부장님과의 카톡 3턴. **당신이 무슨 말을 하느냐**에 따라 5가지 결말로 갈라지는 초간단 대화 시뮬레이션 게임.

🎮 플레이: `https://<아이디>.github.io/quit-job-game/`  (GitHub Pages 배포 후 수정)

## 게임 구조

| 턴 | 부장님의 공격 | 노림수 |
|---|---|---|
| 1 | "요즘 힘들어서 그래? 다 그런 시기 있어" | 감정 공감으로 흔들기 |
| 2 | "1년도 안 됐잖아. 연봉 10% 올려줄게" | 역제안 — 수락하면 즉시 잔류 |
| 3 | "후임 올 때까지는 있어줘야지. 팀 생각도 해야지" | 죄책감 공격 — 날짜를 박아야 통과 |

매 턴 15초 제한. 선택지 3개는 순서가 섞이며, 직접 입력도 가능합니다.

## 판정 방식 (규칙 기반, AI·서버 없음)

`script.js`의 `judge(text, turn)`이 답변을 분석해 **용기 점수**를 가감합니다.

| 감지 | 점수 | 예 |
|---|---|---|
| 퇴사 의사 명시 (`퇴사/사직/그만/퇴직…`) | +2 | "퇴사하겠습니다" |
| 제안 거절 (2·3턴, `아니/안 돼/괜찮/결정…`) | +2 | "연봉 문제 아닙니다" |
| 날짜 명시 (`한 달/다음 달/말까지/N일…`) | +1 (3턴 +2) | "다음 달 말까지요" |
| 금액에 흔들림 (2턴, `얼마/조건/더 주…`) | −2 | "얼마나요?" |
| 애매한 수용 (`적당히/해볼게/후임 오면/알겠…`) | −1 | "네… 후임 오면요" |
| 쿠션어·말줄임 (`죄송/혹시/그게/…/ㅠ/ㅋ…`) | −1개당, 최대 −2 | "그게… 요즘 좀ㅠ" |
| 글자 수 11~20자 / 21자 이상 | −1 / −2 | 장문 설명 |
| 무응답(시간 초과) | −2 | |

### 즉시 엔딩 키워드
- `대행 / 노무사 / 변호사 / 대신 전달` → **퇴사 대행 엔딩**
- `브이로그 / 틱톡 / 큇톡 / 영상 / 때려치 / 욕설` → **큇톡(요란한 퇴사) 엔딩**
- 2턴에서 `감사 / 좋아요 / 알겠습니다 / 다니겠` → **잔류 엔딩**

### 3턴 종료 후
- 용기 **≥ 5** → 🎉 **탈출성공**
- 용기 **0 ~ 4** → 🤫 **조용한 퇴사** (퇴사는 못 했지만 6시 땡 퇴근)
- 용기 **< 0** 또는 도중 **≤ −4** → 😑 **잔류**

실패 화면에서는 턴별로 *어떤 말이 몇 점이었는지* 근거를 보여줘 재도전을 유도합니다.
난이도는 `script.js` 상단 `DIFFICULTY`에서 한 줄로 조절합니다.

## 파일

```
quit-job-game/
├── index.html   # 시작 / 채팅 / 결과 3개 화면
├── style.css    # 메신저 UI, 부장님 표정(data-mood), 결과 애니메이션
├── script.js    # 판정 규칙(RULES) · 대본(SCRIPT) · 엔딩(ENDINGS) · 사운드
└── README.md
```

그림을 바꾸려면 `script.js`의 `BOSS_SVG`(부장님 얼굴)만 교체하면 됩니다. 표정은 `data-mood="neutral|happy|angry|smug|shocked"`로 전환됩니다.
